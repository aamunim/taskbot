# TaskBot নিজের জন্য চালু করার গাইড (A থেকে Z)

এই গাইড ধরে এগোলে আপনার নিজের আলাদা একটা TaskBot চালু হবে: আপনার নিজের বট, নিজের ডেটাবেস, নিজের অ্যাপ। অন্য কারও ডেটার সাথে কোনো সংযোগ থাকবে না।

রিপো: **https://github.com/aamunim/taskbot**

কম্পিউটারে কিছু ইনস্টল করতে হবে না, সব কাজ ব্রাউজার আর Telegram দিয়ে হবে। প্রথমবার পুরোটা করতে আনুমানিক এক থেকে দেড় ঘণ্টা লাগে।

## শুরুর আগে জেনে নিন

### TaskBot কী করে

আপনার বস Telegram গ্রুপে যা লেখেন বা পাঠান (মেসেজ, ভয়েস, ছবি, ফাইল, লিংক), বট সেগুলো সংরক্ষণ করে, AI দিয়ে কাজ, ডেডলাইন ও নোট আলাদা করে, আর একটা Android অ্যাপ ও ওয়েবসাইটে গুছিয়ে দেখায়।

## ধাপ ১: Telegram বট তৈরি

1. Telegram-এ **@BotFather** খুঁজে খুলুন (নামের পাশে নীল টিক আছে যেটায়) এবং **Start** চাপুন।
2. `/newbot` লিখে পাঠান।
3. বটের একটা নাম দিন, যেমন `My Task Bot`।
4. একটা username দিন। এটা অবশ্যই `bot` দিয়ে শেষ হতে হবে, যেমন `rahim_task_bot`।
5. BotFather একটা টোকেন দেবে (`7123456789:AAH...` ধরনের)। এটাই **`TELEGRAM_BOT_TOKEN`**, লিখে রাখুন।

### Privacy Mode বন্ধ করুন (জরুরি)

এটা না করলে বট গ্রুপের সাধারণ মেসেজ দেখতে পাবে না।

1. BotFather-এ `/mybots` লিখুন, আপনার বটটি বেছে নিন।
2. **Bot Settings → Group Privacy → Turn off**।
3. "Privacy mode is disabled" লেখা এলে ঠিক আছে।

### গ্রুপ তৈরি

1. Telegram-এ একটা গ্রুপ খুলুন এবং বসকে যোগ করুন (আগে থেকে গ্রুপ থাকলে সেটাই চলবে)।
2. গ্রুপে আপনার বটকে যোগ করুন।
3. বটকে **অ্যাডমিন** বানান (অনুমতিগুলো বন্ধ রাখলেও চলবে)।

Privacy Mode বন্ধ করার **আগে** বট গ্রুপে যোগ করে ফেললে বটকে একবার সরিয়ে আবার যোগ করুন।

## ধাপ ২: Supabase প্রজেক্ট

1. **supabase.com**-এ অ্যাকাউন্ট খুলে **New project** চাপুন।
2. প্রজেক্টের নাম দিন, কাছাকাছি একটা অঞ্চল বাছুন (যেমন Singapore)।
3. **Database Password**-এ একটা শক্ত পাসওয়ার্ড দিন। এটাই **`SUPABASE_DB_PASSWORD`**, লিখে রাখুন। পরে এটা আর দেখা যায় না, শুধু রিসেট করা যায়।
4. প্রজেক্ট তৈরি হতে দুই-এক মিনিট লাগবে।

এরপর তিনটি মান সংগ্রহ করুন:

- **`SUPABASE_PROJECT_REF`**: প্রজেক্টের ঠিকানা `https://abcdefghijkl.supabase.co` হলে মাঝের `abcdefghijkl` অংশটুকু। ড্যাশবোর্ডের **Project Settings → General**-এ "Project ID" হিসেবেও থাকে।
- **`SUPABASE_ANON_KEY`**: **Project Settings → API Keys** পাতায় `anon` `public` লেখা key (লম্বা, `eyJ...` দিয়ে শুরু)। `service_role` key **নয়**।
- **`SUPABASE_ACCESS_TOKEN`**: ডান উপরে প্রোফাইল → **Account → Access Tokens → Generate new token**।

## ধাপ ৬: GitHub-এ নিজের কপি

1. **github.com**-এ অ্যাকাউন্ট খুলে লগইন করুন।

4. আপনার কপির **Actions** ট্যাবে যান। "Workflows aren't being run on this forked repository" লেখা এলে সবুজ **I understand my workflows, go ahead and enable them** বোতাম চাপুন।

## ধাপ ৭: ব্যাকএন্ড চালু করুন

1. **Actions** ট্যাব → বাঁ পাশে **Deploy backend** → **Run workflow** → সবুজ **Run workflow**।
2. এক-দুই মিনিট পরে রানটা সবুজ টিক পাবে।
3. রানে ঢুকে **deploy** → **Register Telegram webhook and cron** ধাপ খুলুন। সেখানে এরকম একটা লাইন থাকবে:

```json
{"ok":true,"bot":"@your_bot","can_read_all_group_messages":true,...}
```

- `can_read_all_group_messages` যদি `false` হয়: ধাপ ১-এর Privacy Mode বন্ধ হয়নি। সেটা বন্ধ করে বটকে গ্রুপ থেকে সরিয়ে আবার যোগ করুন, তারপর Deploy backend আবার চালান।
- রান লাল হলে নিচের "সমস্যা হলে" অংশ দেখুন।

## ধাপ ৮: ওয়েব ভার্সন চালু করুন

1. আপনার কপিতে **Settings → Pages → Build and deployment → Source**-এ **GitHub Actions** বেছে নিন।
2. **Actions → Deploy web app → Run workflow**।
3. শেষ হলে আপনার ওয়েব ঠিকানা হবে: `https://<আপনার-github-username>.github.io/taskbot/`

## ধাপ ৯: Android অ্যাপ বানান

1. **Actions → Build Android APK → Run workflow**। প্রথমবার ১৫ থেকে ২৫ মিনিট লাগে।
2. শেষ হলে রানের পাতার একদম নিচে **Artifacts**-এ `taskbot-apk` থাকবে। সেটা নামান (GitHub-এ লগইন থাকা লাগবে), zip খুলে `app-release.apk` বের করুন।
3. ফাইলটা ফোনে নিয়ে ইনস্টল করুন। ফোন "অজানা উৎস থেকে ইনস্টল" অনুমতি চাইলে দিন।

## ধাপ ১০: প্রথমবার ব্যবহার

1. অ্যাপ খুলে **Continue with Telegram** চাপুন। Telegram-এ আপনার বট খুলবে, সেখানে **Start** চাপুন, তারপর অ্যাপে ফিরে আসুন। লগইন হয়ে যাবে।
   - **প্রথম যিনি লগইন করেন তিনিই মালিক হন**, পরে আর কেউ ঢুকতে পারে না। তাই বট তৈরির পর নিজে আগে লগইন করুন।
2. গ্রুপে নিজে যেকোনো একটা মেসেজ পাঠান। এতে বট গ্রুপটাকে আপনার বলে চিনে নেয়।
3. পরীক্ষার জন্য গ্রুপে লিখুন: `কাল বিকেল ৫টার মধ্যে রিপোর্টটা পাঠিও`। মিনিটখানেকের মধ্যে বট আপনাকে ব্যক্তিগত চ্যাটে জানাবে আর অ্যাপের Tasks-এ কাজটা দেখা যাবে।
4. বস গ্রুপে একটা মেসেজ দেওয়ার পর অ্যাপের **Settings → People → Change**-এ গিয়ে তাঁকে বস হিসেবে বেছে নিন। গ্রুপে শুধু আপনারা দুজন থাকলে বট নিজেই ঠিক ধরে নেবে।

এখন থেকে বস গ্রুপে যা পাঠাবেন তা নিজে থেকে গোছানো হবে।

## দরকারি সেটিংস

অ্যাপের **Settings**-এ:

- **Tell your boss:** বসের কাজে Done চাপলে বট গ্রুপে তাঁকে জানাবে কি না।
- **Automation:** অস্পষ্ট নির্দেশনায় প্রশ্ন, বস উত্তর না দিলে ফলো-আপ, সাপ্তাহিক রিপোর্ট। এগুলো গ্রুপে পাঠানোর আগে বট আপনার অনুমতি নেয়।
- **Page for your boss:** বসের জন্য একটা গোপন লিংক, যেখানে তিনি লাইব্রেরির ফাইল ও লিংক দেখতে ও নামাতে পারেন।
- **Reminders:** সকালের সারাংশ আর ডেডলাইনের সতর্কবার্তার সময়।
- **Appearance:** রঙ, ডার্ক মোড, লেখার আকার।

বটের সাথে ব্যক্তিগত চ্যাটে `/today` লিখলে আজকের তালিকা আসে, আর যেকোনো প্রশ্ন করা যায় (যেমন "এই সপ্তাহে কী বাকি?")।

## পরে নতুন সংস্করণ নিতে চাইলে

মূল রিপোতে নতুন ফিচার এলে:

1. আপনার কপির প্রথম পাতায় **Sync fork → Update branch** চাপুন।
2. ক্রমানুসারে চালান: **Deploy backend**, তারপর **Deploy web app**, তারপর **Build Android APK**।
3. নতুন APK আগেরটার উপরেই ইনস্টল করুন। ডেটা হারাবে না, কারণ সব ডেটা Supabase-এ থাকে।

### ঐচ্ছিক: APK ছাড়াই অ্যাপ আপডেট

প্রতিবার APK বানাতে না চাইলে Expo-র আপডেট ব্যবস্থা চালু করা যায়:

1. **expo.dev**-এ অ্যাকাউন্ট খুলে `taskbot` নামে একটা প্রজেক্ট বানান।
2. আরও তিনটি secret যোগ করুন: `EXPO_TOKEN` (Account Settings → Access Tokens), `EXPO_PROJECT_ID` (প্রজেক্টের পাতার Project ID), `EXPO_OWNER` (আপনার Expo username)।
3. **Build Android APK** একবার চালিয়ে নতুন APK ইনস্টল করুন।
4. এরপর থেকে অ্যাপের পরিবর্তনের জন্য শুধু **Publish app update** চালালেই হবে।

এই তিনটি secret না বসালে আপডেট ব্যবস্থা বন্ধ থাকে, আর অ্যাপ শুধু নতুন APK ইনস্টল করলেই বদলায়। সেটাও পুরোপুরি ঠিক আছে।

## সমস্যা হলে

| কী হচ্ছে | কী করবেন |
|---|---|
| Actions ট্যাবে workflow দেখা যাচ্ছে না | ধাপ ৬-এর সবুজ "enable" বোতাম চাপা হয়নি |
| Deploy backend: "Missing repository secret" | ওই নামের secret বসানো হয়নি বা নামে ভুল আছে |
| Deploy backend: Link project ধাপে ব্যর্থ | `SUPABASE_ACCESS_TOKEN`, `SUPABASE_PROJECT_REF` বা `SUPABASE_DB_PASSWORD` ভুল |
| `can_read_all_group_messages: false` | Privacy Mode বন্ধ করে বটকে গ্রুপে আবার যোগ করুন |
| অ্যাপে লগইন হচ্ছে না | Deploy backend সফল হয়েছে কি না দেখুন; বটের চ্যাটে Start চেপেছেন কি না |
| "This bot is for someone else's private use" | আপনার আগে অন্য কেউ লগইন করে মালিক হয়ে গেছেন। Supabase-এর Table Editor-এ `app_config` টেবিলে `owner_tg_id` আর `owner_user_id` ফাঁকা করে আবার লগইন করুন |
| গ্রুপের মেসেজ অ্যাপে আসছে না | গ্রুপে নিজে একটা মেসেজ দিয়েছেন তো? বট গ্রুপের সদস্য ও অ্যাডমিন তো? |
| কাজ তৈরি হচ্ছে না, কিন্তু মেসেজ Timeline-এ আছে | Claude-এ ক্রেডিট আছে কি না দেখুন; অ্যাপের Settings → Bot status-এ শেষ এরর দেখুন |
| ভয়েসের লেখা আসছে না | ElevenLabs-এর মাসিক বরাদ্দ শেষ হয়ে থাকতে পারে |
| ওয়েব ঠিকানায় 404 | ধাপ ৮-এর Pages Source "GitHub Actions" করা হয়নি, বা Deploy web app চলেনি |
| বসের নাম তালিকায় নেই | বস গ্রুপে অন্তত একটা মেসেজ দেওয়ার পর আবার দেখুন |

Supabase-এর বিনামূল্যের প্রজেক্ট এক সপ্তাহ কোনো ব্যবহার না থাকলে নিজে থেকে থেমে যেতে পারে। তখন Supabase ড্যাশবোর্ডে গিয়ে **Restore** চাপলেই আবার চালু হয়।

## গোপনীয়তা নিয়ে যা জানা দরকার

- গ্রুপের মেসেজ, ছবি ও ভয়েস বিশ্লেষণের জন্য Claude আর ElevenLabs-এ পাঠানো হয়, আর আপনার Supabase প্রজেক্টে জমা থাকে। অফিসের গোপনীয় তথ্য থাকলে বসকে জানিয়ে নিন।
- আপনার ডেটা শুধু আপনার নিজের Supabase প্রজেক্টে থাকে। মূল রিপোর মালিক বা অন্য কেউ তা দেখতে পান না।
- ওয়েব ঠিকানাটা যে কেউ খুলতে পারে, কিন্তু আপনার Telegram দিয়ে লগইন ছাড়া কিছুই দেখা যায় না।
- আটটি secret কখনো কাউকে দেবেন না। কোনোটা ফাঁস হয়েছে মনে হলে সেই সার্ভিসে গিয়ে নতুন বানান, GitHub-এ বদলে দিন, আর Deploy backend আবার চালান।
